# Thermocrystals

Исторический исследовательский проект по моделированию распределения частиц и теплопереноса. Исходный код написан для Qt: он содержит генерацию случайных величин, расчёты и построение графиков через виджеты интерфейса.

## Запускаемый пример

`examples/heat_demo.cpp` показывает один из численных принципов теплопереноса: явное одномерное уравнение диффузии с теплоизолированными границами. Центральная ячейка сначала нагрета до 100 условных единиц, остальные до нуля; программа записывает эволюцию в CSV и проверяет сохранение суммарного тепла.

```bash
g++ -std=c++17 -Wall -Wextra -Werror -O2 examples/heat_demo.cpp -o heat_demo
./heat_demo 21 100 heat.csv
```

Коэффициент шага равен `0.25`, что удовлетворяет ограничению устойчивости явной схемы `<= 0.5`. GitHub Actions компилирует и выполняет пример. Он иллюстрирует метод и **не заменяет** модель взаимодействия частиц из исторического кода.

## Историческая реализация

`legacy_particle_distribution.cpp` зависит от отсутствующих `particle_distribution.h`, Qt формы `ui_particle_distribution.h` и графического компонента QCustomPlot. Файл сохранён как исследовательский материал; сборка полного Qt приложения из этого репозитория невозможна.
